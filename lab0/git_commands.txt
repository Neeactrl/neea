git clone копирует репозиторий на компьютер
git status показывает состояние файлов
git add добавляет изменения к коммиту
git commit сохраняет изменения в истории
git push отправляет изменения на удалённый репозиторий
git pull загружает последние изменения
git init создаёт новый репозиторий
git log показывает историю коммитов
git branch управляет ветками
git checkout переключает ветки или версии файлов
